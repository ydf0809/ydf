# 双板FPGA视觉识别与运动控制平台设计说明

版本：工程预览；整理日期：2026-11-02。本文基于本次指定主工程和实际验证结果重新编写。作品正式名称、应用背景、相关工作及原始实测材料待所有者补充。

## 1. 问题与应用

工程将图像采集、视觉处理、语音输入和移动执行机构连接为双板系统。当前可从源码核对的是模块组成和控制接口；具体应用价值、创新点、相对既有方案的差异，须结合所有者的需求和测量说明，不因功能组合直接宣称领先。

## 3. 硬件划分与接口

两板目标器件均为XC7Z020CLG400-1，顶层分别为top与super_top。当前交付以PL侧RTL为主，没有额外引入PS程序、HLS或PYNQ迁移。上下板之间采用UART传递模式、框与循迹相关状态。

上层保持原始RGB识别通路；运动/候选定位、ROI和SCNN分类具有不同职责。下层按模式选择底盘、视觉与机械臂相关控制。物理引脚以XDC有效约束和board/pinmap.csv为依据，不从旧注释推断实际接线。

选择双板划分的原始设计依据、吞吐量、控制延迟和资源代价的量化论证待补充。

## 4. 关键控制机制

- 上层锁定逻辑包含周期复检、目标丢失复核及模式切换；相关边界由原工程四个测试台覆盖。
- 串口链路连接模式、目标信息与循迹输入，验证重点包括解析、错误帧、模式切换与消息时序。
- 下层的停止、I2C发送完整性和机械臂状态需要在模块测试之外继续做实际执行机构观察。

本次开源整理不修改这些算法、阈值、接口或时钟；仅调整工程交付路径与运行脚本。
