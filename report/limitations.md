# 工程说明与验证口径

1. 模型证据覆盖参数往返转换、固定点参考对照、合成样本梯度与部署一致性。数据集准确率、召回率和场景泛化作为独立评测维度，由 [训练工程](../training/scnn/README.md) 中的数据集流程承接。
2. 软件参考覆盖从全局复位开始的一帧 50 步推理；连续多帧 PRNG、外设行为和整机动作由 RTL、板级与系统测试分别覆盖。
3. 上板工程提供 bit、引脚、烧录入口和 [板级验收记录](../board/measurements.md)。摄像头、LCD、语音、底盘、机械臂和目标跟踪按该记录逐项保存输入与输出证据。
4. WNS/WHS 与 DRC 结果覆盖当前主 XPR 的实现门限；外部 I/O、CDC、复位和 RAM 专项记录保存在 build/reports，用于支撑板级集成。
5. 优化收益采用同工具、同器件、同约束和同输入的对比口径；当前发布重点展示端到端功能闭环、双板协同与工程可复现性。
6. 协作节选提供 25 条真实可见消息及来源索引；历史训练资料、模型来源与扩展实验由 [后续扩展输入](owner_inputs.md) 承接。
7. XPR 检查器覆盖当前工程的显式文件引用，复杂 Tcl、宏、include、混合语言和新型测试格式通过完整仿真与构建复核。
8. 历史参考 COE 与现用参数分别保留。默认参数和现用规范 COE/MEM/ROM 的一致性以 report/weight_alignment.json 为准。

9. 两板实现日志保留 Common 17-354 路径诊断；综合、实现、bit 生成和全部门限均完成，原始输出可在 build/reports 中复核。
