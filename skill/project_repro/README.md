# XPR工程依赖检查

## 适用范围

适用于以XPR保存文件引用、文件真实位于项目目录内的Vivado工程。复制本目录即可使用，Python3.10以上，无第三方包依赖。

~~~text
python check_xpr.py --root "<project_root>" --xpr "vivado/project.xpr"
~~~

可重复传入--xpr。返回JSON含引用数量、缺失文件、越出根目录文件和未识别宏；全部通过返回0，否则返回1。先故意移走一个已引用文件，确认检查失败，再恢复并确认通过。

## 来源与已验证效果

本项目迁移时需要处理中文导入目录、XPR来源提示和可选旧增量检查点。该检查用于两套主工程，证明被解析的文件引用存在且在指定根内；本次具体结果保存于仓库验证记录。它不推断编译正确或文件许可。

## 失效条件

只展开PPRDIR、PSRCDIR、PGENDIR、PRUNDIR四类常见宏，其他宏明确报未解析。不能发现任意Tcl在运行时新增的文件、HDL动态拼接的数据路径或网络依赖；仍需实际构建与人工核对。使用相应平台的Vivado生成环境文件，不能将本脚本通过当作跨平台构建承诺。
