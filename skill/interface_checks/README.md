# 视觉与控制接口踩坑清单

适用于跟踪、模式切换、串行链路、CDC 和执行机构 RTL。可迁移的是定位方法，阈值、协议、时钟与动作范围须重新定义。

## 1. 延长保锁反而更久跟错目标

- **触发**：亮块接近，框被吸走却维持锁定。
- **来源**：excerpt_07—10。历史合成场景加入亮块后中心从 (300,200) 变为 (324,192)，位置仍有效。
- **排查**：分开观察位置、身份与锁定；先分辨框漂移还是分类后脱锁，反差峰值不是同一目标证据。
- **处理**：候选参考、位置连续确认；复检按已完成结果累计，忙碌跳过不算阴性。
- **验证**：tb_motion_detector、tb_motion_candidate_priority、tb_periodic_recheck、tb_integrated_recheck_cdc。
- **边界**：合成反例不覆盖实拍所有场景；当前RTL采用2秒周期和无人机脉冲数≤10的复核条件，参数以源码为准。

## 2. 重复同一模式，旧锁定残留

- **触发**：再次发防空命令，mode 未变，仅靠状态边沿不能复位。
- **排查**：区分命令事件/状态；追踪锁定、外观参考、分类历史、未完成推理与发送队列。
- **处理**：定义重新进入事件和跨域复位契约，旧结果不能更新新会话。
- **验证**：tb_air_defence_mode、tb_roi_scheduler、tb_integrated_recheck_cdc 及串行兼容测试。
- **边界**：不证明机械回位速度、限位或负载已实测。

## 3. 多位目标框跨域拼成不存在的框

- **触发**：多位总线逐位同步，或只同步 valid。
- **排查**：检查数据稳定区间、request/acknowledge、模式与复位归属。
- **处理**：发送端冻结完整快照，握手后接收端统一采纳。
- **验证**：tb_camera_box_cdc、tb_integrated_recheck_cdc，覆盖更新期间模式切换/复位。
- **边界**：功能仿真不能测亚稳态概率，仍需 CDC 报告与实现验证。

## 4. 停止请求打断 I2C 包

- **触发**：忙碌时修改当前包或丢弃新停车请求。
- **排查**：逐级追踪请求、忙碌、包快照、完整事务；速度变量为 0 不等于电机已收停车包。
- **处理**：当前事务原子完成，排队保留最新请求，结束后发送完整停车。
- **验证**：tb_iic_stop、tb_chassis_filter、tb_xunbi_tracking，观察完整包与时间。
- **边界**：不覆盖从机离线、供电、机械惯性，不能承诺立即物理停车。

## 5. 默认参数改了，实例覆盖仍是旧值

- **来源**：excerpt_11—14。corner_turn 默认改 1000 ms，xunbi_core 仍传 300。
- **排查/处理**：从顶层查真实实例和覆盖，再确认 XPR 编译该文件。
- **验证**：tb_corner_turn、tb_xunbi_tracking 检查转弯前四轮指令和持续时间，不只检查参数文本。
- **边界**：时钟、分频和仿真加速变化时重新换算。

## 6. 算术流水正确，同步信号错位

- **触发**：RGB→HSV 增寄存器，frame/line/valid 没同步延迟。
- **排查**：同时检查像素值、有效、同步和地址。
- **验证**：tb_rgb2hsv_pipeline 对 65536 种 RGB565 对照；tb_ov7670_capture 检查采样/blanking，tb_camera_box_cdc 检查框。
- **边界**：不是摄像头/LCD 实测；实际 PCLK 和外部 I/O 延迟仍需测量。
