# 定点模型与 FPGA 部署踩坑清单

适用于固定点卷积/全连接网络的参数转换与 ROM 部署。换网络时须重新定义形状、lane、溢出和复位语义；不覆盖数据代表性、泛化或硬件闭环性能。

## 1. 同名 COE/MEM 不保证同一套参数

- **现象/触发**：历史导出混放，同名文件推理不同。
- **证据**：协作 excerpt_01—06。历史参考 COE 与现用参数有 3414/3416 个值不同；当前规范 COE/MEM 已一致，不能把历史差异说成现用文件仍冲突。
- **排查**：分别解析 header、宽度、深度和 signed16，比较实际登记的内嵌 ROM，再比较生成器；不能只看文件名或文件哈希。
- **处理**：选择权威参数，历史参考分开命名。当前默认 `parameters/final_engine_weights.json`。
- **验证**：`python build/check_weights.py` 比较规范 COE/MEM、默认 JSON、4 个权重 ROM 和 1 个帧 ROM；训练 verify.py 拒绝混合格式。
- **失效条件**：烧录旧 bit、编译另一份 ROM、模型结构改变；数值相同不代表板上已更新。

## 2. 复制 COE 不会替换已内嵌 ROM

- **触发**：RTL 已有常量，只更新外部 COE。
- **定位**：查 XPR 登记和 ROM 实例，本工程实际源为 `rtl/drone_data_roms.v`。
- **处理**：导出 ROM→审核替换→相关仿真→主 XPR 重建；转换器不自动改硬件工程。
- **验证**：生成数据、登记 ROM、主 run bit 与发布 bit 的哈希/数值对应，见 report/weight_alignment.json 和构建 manifest。
- **边界**：转换成功不证明新模型识别能力或硬件结果。

## 3. RGB 文件不等于 RGB 张量顺序

- **触发**：RRGGBB 帧按低字节取通道 0。
- **定位/处理**：核对 input_frontend 位选；用单通道哨兵。本工程张量 B/G/R，类别 0=not_drone、1=drone，平票取 0。
- **验证**：编码复位、独立打包哨兵和整数对照；参考帧 [0,50]、黑帧 [0,0] 仅为功能参考。
- **边界**：相机顺序、RGB565 扩展或预处理改变后重新验证，不能凭图片颜色推断张量。

## 4. 卷积与 FC 字内顺序不同

- **触发**：统一使用一种大小端展开宽字。
- **定位**：卷积低 lane 对应 ci=0/co=0；FC 64 位字高 16 位是四个特征中的第一个。
- **处理/验证**：用非对称 1、-1、32767、-32768 哨兵，独立核查位置，不只用同函数解包再打包。verify.py 检查 lane 与 3416 参数往返。
- **边界**：并行度、形状、位宽变化须重写映射。

## 5. 实数近似相同不等于固定点相同

- **触发**：负奇数右移、阈值附近或溢出时差一个脉冲。
- **排查**：16 位 Q12、26 位 signed 回绕、算术右移、发放清零；从第一处脉冲差异追踪。
- **验证**：verify.py 对参考/黑帧比较完整 50 步与独立 NumPy 整数实现，覆盖负奇数与边界。
- **边界**：从全局复位的一帧开始，不证明连续帧 PRNG、全部图像或端到端 RTL 形式等价。

## 6. 合成训练 PASS 不代表数据集准确率

- **触发**：梯度、loss 或导出成功被写成正式训练完成。
- **处理**：区分转换验证、流程测试、正式训练及独立评测；记录数据哈希、划分和指标定义。
- **已验证**：2 个合成输入、3 步，三个张量有梯度并更新，检查点可导出。
- **边界**：无正式数据集，不报告准确率/泛化；50 个输出脉冲不是 100% 准确率。
