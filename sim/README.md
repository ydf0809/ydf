# 原始测试台回归

测试台直接取自指定的两套主工程：上层4项，下层12项。未从旧审核材料导入测试或结论。

~~~text
python sim/run.py --vivado-bin "<vivado_install>/bin" --board all
~~~

每个测试建立独立工作目录，按模块实例依赖选择所需RTL，用原始语言模式编译，并在xelab设置默认timescale。这样不会因无关模块的解析错误把独立测试统一判为功能失败。源码不因此改写。

通过条件为：工具退出成功、输出包含原测试台定义的明确通过语句，且没有失败/错误语句。编译失败、展开失败、功能失败、超时分别记录。工作文件放work/；公开日志与[汇总](results/summary.json)放results/。

## 覆盖范围

- 上层：保锁策略、周期复检、分类结果跨域及采集握手、防空模式切换。
- 下层：目标框解析、板间链路、机械臂跟踪与停止、模式切换、底盘滤波、直角转弯、旋转、I2C停止及循迹控制。

这些测试不是完整摄像头图像集准确率测试，也不等同于物理双板闭环、机械臂负载、电机响应或整机安全测试。识别准确率、误报/漏报、实际时延与行为成功率须使用独立实测数据。
