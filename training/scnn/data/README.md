# 无人机识别数据集规范

模型训练采用无人机与非无人机二分类数据。图像应完成与摄像头输入链一致的 ROI 预处理，并按以下结构配置训练集与验证集：

```text
data/
  train/
    not_drone/
    drone/
  val/
    not_drone/
    drone/
```

- 类别索引 0 对应 `not_drone`，类别索引 1 对应 `drone`，目录名称与类别映射保持固定。
- 每个类别在训练集和验证集中均应包含图像。每张图像尺寸为 64×64，保留彩色信息；程序自动转换为 B/G/R 张量顺序，不执行缩放、灰度化、二值化或标准化。
- 数据预处理应与部署输入一致，包括 RGB565 通道展开及 128×128 ROI 到 64×64 输入的 2×2 均值采样。
- 连续视频数据应按拍摄片段或场景划分训练集与验证集。程序拒绝两个集合中逐字节相同的图像文件，并在训练时保存数据文件清单及 SHA-256。
- 数据文件应实际位于项目目录内，不使用项目外绝对路径或越界软链接。
- 当前目录未配置完整的训练集与验证集。正式训练前应补齐上述目录和数据；功能验证所用合成输入及参考帧不计入数据集规模。
